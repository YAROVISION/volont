# Binance Volume Surge Monitor & Telegram Alerter

Це ультра-легкий локальний додаток, написаний на Python (асинхронний бекенд) та Vanilla JS (преміальний веб-інтерфейс), призначений для моніторингу об'ємів торгів криптовалютних пар на біржі Binance в реальному часі.

Система автоматично виявляє сплески об'єму торгів на будь-якій парі до USDT на 10% або більше порівняно з середнім базовим рівнем за останні 14 хвилин та миттєво сповіщає про це в Telegram і на локальний дашборд.

---

## Особливості архітектури (Ultra-Lightweight Stack)

*   **Python Backend (server.py):**
    *   Використовує асинхронні WebSocket-клієнти для збору угод (Trade streams) з Binance (розділені на чанки по 150 монет для надійності).
    *   Обробка вхідних угод та розрахунок ковзних хвилинних вікон виконується виключно **in-memory** в оперативній пам'яті (без використання SQL або NoSQL БД).
    *   Локальний WebSocket-сервер транслює виявлені аномалії на веб-інтерфейс.
    *   Сповіщення в Telegram надсилаються асинхронно через HTTP POST запити до Telegram Bot API.
*   **Vanilla JS Frontend (index.html):**
    *   Має сучасний інтерфейс у стилі Dark Mode / Glassmorphism.
    *   Приймає алерти через локальний WebSocket.
    *   Підключається безпосередньо до Binance WebSocket для обраної в терміналі монети, щоб виводити Order Book (стакан) та стрічку угод в реальному часі. Це мінімізує навантаження на локальний Python-сервер та пам'ять браузера.

## Швидкий запуск

### 1. Встановлення залежностей

Переконайтеся, що у вас встановлено Python 3.11+. Встановіть необхідні бібліотеки командою:

```bash
pip install -r requirements.txt
```

*(Якщо виникає помилка доступу до системних каталогів, використовуйте `--user`):*
```bash
pip install --user -r requirements.txt
```

### 2. Налаштування Telegram (Опціонально)

Відкрийте файл `server.py` і замініть значення конфігурації вашими ключами, або задайте їх через змінні середовища перед запуском:

```python
TELEGRAM_TOKEN = "YOUR_TELEGRAM_BOT_TOKEN"
TELEGRAM_CHAT_ID = "YOUR_CHAT_ID"
```

Якщо ви хочете змінити ліміт мінімального об'єму для алертів (за замовчуванням $10,000` USDT, щоб відсіяти неліквідні монети), відредагуйте:
```python
MIN_VOLUME_USD = 10000
```

### 3. Запуск бекенд-сервера

Запустіть Python-сервер з терміналу:

```bash
python server.py
```

Ви повинні побачити повідомлення про успішне підключення до Binance Exchange Info та запуск WebSocket потоків.

### 4. Запуск веб-інтерфейсу

Просто двічі клікніть або відкрийте файл `index.html` у вашому улюбленому браузері (Chrome, Firefox, Edge, Safari).
*   У правому верхньому куті має загорітися **зелений індикатор "Бекенд: Підключено"**.
*   Почнеться автоматичний рендеринг склянок та торгів для `BTCUSDT`.
*   При отриманні перших сигналів від сервера ліва панель почне заповнюватися анімованими золотистими картками алертів. Клік по картці автоматично оновить термінал для відповідної монети.
