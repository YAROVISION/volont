# Візуальна система (Design System)
*Розроблено на основі референсу "Screenshot 2026-08-12 164402.jpg"*

## 1. Концепція та настрій (Vibe & Concept)
Дизайн поєднує строгість архітектурних креслень (blueprints) із сучасними, сміливими та яскравими акцентами. Він передає відчуття точності, інженерної думки, креативності та інноваційності.

## 2. Кольорова палітра (Color Palette)
*   **Глибокий синій (Blueprint Blue):** Основний колір фону. Створює асоціацію з технічними кресленнями. (Орієнтовний HEX: `#2c4c82`)
*   **Яскравий помаранчевий (Construction Orange):** Головний акцентний колір. Використовується для виділення важливих блоків, карток або кнопок заклику до дії (CTA). (Орієнтовний HEX: `#ef633e`)
*   **Електричний синій (Electric Blue):** Додатковий акцентний колір. Добре контрастує з помаранчевим і гармоніює з основним синім. (Орієнтовний HEX: `#2a6de1`)
*   **Білий (White):** Використовується для тексту, ліній сітки та логотипів на темному/синьому тлі. (HEX: `#ffffff`)
*   **Вугільний чорний (Charcoal/Black):** Використовується для тексту та графіки на світлих або яскравих фонах (наприклад, на помаранчевому). (Орієнтовний HEX: `#111111`)
*   **Крафтовий бежевий (Kraft Paper/Sand):** Фоновий колір для підкладок, що додає текстури та відчуття фізичного матеріалу. (Орієнтовний HEX: `#d6ccba`)

## 3. Типографіка (Typography)
*   **Шрифт:** Сучасний геометричний гротеск (Sans-serif). Рекомендовані шрифти: *Inter, Helvetica Neue, Roboto* або *Space Grotesk* (для більш технічного вигляду).
*   **Заголовки (Headings):** Чіткі, великі, накреслення Bold або Medium. Текст заголовків вирівнюється по лівому краю. Приклад: "Your sketches super-powered."
*   **Основний текст (Body text):** Дрібний, накреслення Regular. Використовується для описів та додаткової інформації.
*   **Колір тексту:** Білий на синьому тлі, чорний — на помаранчевому/світло-синьому.

## 4. Графічні елементи та UI-патерни
*   **Сітки та креслення (Grids & Guides):** Тонкі білі лінії (ортогональні та полярні/радіальні сітки), що створюють ефект міліметрівки або архітектурного плану. Это ключовий елемент фону.
*   **Ізометричні ілюстрації:** Використання лінійних 3D-малюнків (isometric line art), що зображують архітектурні форми або механізми.
*   **Геометричний мінімалізм в іконках:** Логотип та іконки побудовані на основі базових геометричних фігур (квадрат, коло, трикутник). Лінії іконок мають бути однакової товщини.
*   **Багатошаровість (Layering):** UI має імітувати фізичні об'єкти (аркуші паперу, візитки), що лежать один на одному з легкими, реалістичними тінями (drop shadows) для створення глибини.
*   **Мікроелементи:** Використання дрібного технічного тексту (наприклад, розміри сітки "295.42  454.85" або мітки вирівнювання) для підтримки загальної стилістики.

## 5. Рекомендації щодо структури веб-сторінки
*   **Hero Section:** Фон — "Blueprint Blue" із видимою радіальною та лінійною сіткою. Великий білий заголовок зліва. Справа або по центру — "картка" яскраво-помаранчевого кольору з ізометричною графікою, що накладається поверх фону з тінню.
*   **Картки (Cards):** Інформаційні блоки варто оформлювати як окремі "аркуші" кольорового паперу (помаранчеві, сині), накладені на загальний синій або крафтовий фон.
*   **Кнопки (Buttons):** Прямокутні, строгі форми без заокруглень (border-radius: 0). Колір — помаранчевий або яскраво-синій.
